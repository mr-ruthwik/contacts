# 📞 Contact Management System

A sleek, professional, and dark-themed web application built with **Flask** and **Python** to manage your contacts effortlessly.

## 🚀 Features

* **Intuitive Dashboard**: A clean welcome screen with easy-to-use navigation.
* **CRUD Functionality**: Create, Read, Update, and Delete contacts seamlessly.
* **Professional UI**: Dark theme aesthetic with responsive card-based layouts and FontAwesome iconography.
* **Dynamic Feedback**: Real-time status notifications for all actions, with automatic input clearing for a smooth user experience.
* **Responsive Design**: Centered and width-optimized layout for a polished, app-like look.

## 🛠 Tech Stack

* **Backend**: Python, Flask
* **Frontend**: HTML5, CSS3, JavaScript (Fetch API)
* **Icons**: FontAwesome

## 📋 Installation & Setup

1. **Clone the repository**:
```bash
git clone https://github.com/mr-ruthwik/contacts.git
cd contacts

```


2. **Install dependencies**:
```bash
pip install -r requirements.txt

```


3. **Run the application**:
```bash
python app.py

```


4. **Access the app**:
Open your browser and navigate to `http://127.0.0.1:5000`.

## 📂 Project Structure

* `app.py`: The main Flask server handling routing and logic.
* `contact_manager.py`: The backend logic managing the contact data.
* `index.html`: The frontend structure and client-side JavaScript.
* `style.css`: Custom CSS for the dark theme and responsive layout.
* `requirements.txt`: Project dependencies.
